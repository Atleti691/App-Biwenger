# Liga Amigos XI Administración

Proyecto inicial de la aplicación Django para gestionar divisiones, jornadas,
porras, quinielas y clasificaciones.

## Estado inicial

- Estructura base preparada para Django.
- Usuarios y divisiones documentados.
- Credenciales iniciales guardadas en `config/initial_credentials.txt`.
- Las contraseñas son temporales y deben cambiarse en el primer acceso.
- Las nuevas contraseñas no se guardan en archivos: Django almacena hashes seguros.
